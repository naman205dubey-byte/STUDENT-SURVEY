# STUDENT-SURVEY-DASHBOARD

An interactive Power BI dashboard that analyzes student purchasing behavior and store performance.  
The dashboard highlights key metrics such as average items per student, average revenue per student, total items sold, and total revenue.

## Purpose
The Student Survey Dashboard helps analyze how students spend in the campus store by exploring product categories, age groups, store locations, and yearly revenue trends.

## Tech Stack
- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling

## Data Source
Sample Student Store dataset containing:
- Age category
- Item categories
- Store location
- Payment method
- Quantity and revenue

## Key Insights
- Avg Items per Student: **157.69**
- Avg Revenue per Student: **851.57**
- Total Items Sold: **119K**
- Total Revenue: **642.08K**

## Dashboard Features
- Revenue trend by year
- Purchase analysis by age category
- Category-wise sales distribution
- Store location performance
- Academic vs Non-academic book comparison
